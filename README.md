## 打开方式

直接双击 [`index.html`](index.html)，或用浏览器打开：

```bash
open index.html
```

> 首次打开约 2.5 MB，现代浏览器可即时渲染；后续从本地缓存读取。

## 功能

- **按年份阅读**：左侧年份直接跳转；阅读按 Text 1—4 分栏，小三门按完形 / 新题型 / 翻译分栏。
- **逐题卡片**：答案、题型、定位句、可用方法（主 / 辅）、解析、讲义对应、避坑；小三门另有方法、线索、排除；翻译有意群切分、采分点、参考译文。
- **阅读题干与选项中英对照**：阅读 Part A 的 440 道题全部补入英文题干与 A—D 选项，并配中文翻译；练习模式下先隐藏中文，点“显示答案”后与答案一起出现。
- **完形选项释义**：340 空 × 4 个选项全部补中文释义（1360 条），按语境取义；练习模式下先隐藏，点“显示答案”后与答案一起出现。
- **完形出题句**：340 空逐条给出含空格的完整出题句，英文与中文上下对照；当前空用红色标记，同句其他空用青色标记；练习模式下中文先隐藏。
- **练习模式**：右上角开关，遮住答案与正确选项，点击“显示答案”逐题揭示；完形 / 新题型原文中的空格也可点击查看答案。
- **全文搜索**：按 `/` 聚焦，支持中文概念、英文原词、方法名、年份、题号；可按阅读 / 完形 / 新题型 / 翻译筛选。
- **方法索引**：阅读 28 种方法按使用频次统计，点方法反查题目；小三门 X/P/H/L/C/T 共 33 条代号，点代号反查题目。
- **答案速查**：22 年阅读四篇答案表；17 年小三门完形答案串与新题型答案。
- **星标与进度**：卡片右上角星标，记录待复习题（保存在本机 localStorage）；深色 / 浅色主题可切换。
- **手机适配**：窄屏自动收起侧栏，文章与题目按单列重排。
- **打印**：`Cmd/Ctrl + P` 可打印当前页，解析自动展开。

```

└─ src/

   ├─ style.css               # 样式
   ├─ app.js                  # 路由、渲染、搜索、练习模式等
   ├─ opt_zh.json             # 完形 1360 个选项的中文释义
   ├─ cloze_sentences.json    # 完形 340 条出题句及中译
   └─ reading_questions.json  # 阅读 440 题的题干、选项与中译
```

## 重新生成

数据源变化后，在 `真题解析网站/` 下执行：

```bash
python3 build_site.py
```

脚本会读取：

- `../阅读/成稿/书稿源文件.md`
- `../阅读/成稿/阅读题目与翻译.json`（缺失时用 `src/reading_questions.json`）
- `../小三门/解析工程/方法体系.md`
- `../小三门/解析工程/data/*.md`
- `../小三门/解析工程/out/*.json`
- `../小三门/解析工程/opt_zh.json`（缺失时用 `src/opt_zh.json`）
- `../小三门/解析工程/cloze_sentences.json`（缺失时用 `src/cloze_sentences.json`）

并重新生成 `index.html`。调试时可加 `--dump`，额外输出 `src/data.json`。

## 数据与口径

- **阅读**：以《颉斌斌阅读方法论》公开讲义为底本，覆盖 2005—2026 年英语（一）88 篇、440 题；每题固定七字段：答案、题型、定位、可用方法、解析、讲义对应、避坑。题干与选项据真题卷 OCR 整理，清理了页码、水印与常见识别错字，并逐题配中文翻译；翻译以“准确、像中文试卷”为准，标题/专名保留必要信息。
- **小三门**：依据课堂笔记整理的方法体系，覆盖 2010—2026 年完形 340 空、新题型 85 题、翻译 85 句；每题固定“方法—线索—解析—排除”，翻译另加意群切分、采分点、参考译文。
- **完形选项释义**：340 空共 1360 个选项；同一单词在不同语境下分别取义，不是一份通用词表。释义列在选项原文下方，练习模式下暂隐。
- **完形出题句**：340 条，取自完形原文中含空格的整句；同句含多个空时全部保留，当前空高亮；中文按中文语序摆放空格标记，不把答案词填入。
- **阅读题目译文**：440 道题干 + 1760 个选项；题干若在选项处截断，中文以“……”自然收尾；专名用通行译名，个别缩写保留英文。
- **答案**：以官方卷面答案为准；小三门完形另做过 A/B/C/D 分布校验。
- **方法统计**：按每题“可用方法”字段的规范名计数，一题可计多种方法；与书稿附录的统计口径可能有一两题的出入，以题目字段为准。
- **阅读部分不含原卷全文**：书中只收“文章速读 + 逐题解析”，每题“定位”栏已标明段句并引用原文；做题时请配合真题卷。小三门则收录了完形 / 新题型 / 翻译的原文。
